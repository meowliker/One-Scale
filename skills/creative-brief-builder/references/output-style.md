# Output Style

Strategists read these messages fast, often on a phone, then forward parts to editors. Every message should look clean and organised: the same sections in the same order every run, mostly tables, and almost no paragraphs.

## Rules

- **Tables over text.** Anything with 2+ items or 2+ attributes goes in a table. Use two-column `| | |` tables for cards (hook card, data card, format summary).
- **One-line intro, no preamble.** Start with a single line saying what this message is ("Breakdown + options for SleepyBear → Dreamy Tales, hook-text borrow."). No "Great question!" or restating the request.
- **Fixed section headers**, in this order, using these exact markers so every run looks the same:
  - `## 🎬 Inspiration breakdown`
  - `## 📊 Our data`
  - `## 🔁 Conversion` (full copy / format only)
  - `## ✍️ Options`
  - `## 👉 Your pick`
  - `# 🎬 Editor Brief: …` (final brief, its own message)
- **`---` between sections.**
- **Quotes for exact words** (`"Always Feeling BLOATED?"`), **bold** for the key word in a cell, `→` for sequences.
- **Short cells.** Aim for under ~25 words per cell (the beat table's content column can run longer). If a cell needs more, the row is probably two beats.
- **No walls of text.** Max 2–3 lines for any paragraph. Analysis goes into the "Narrative role", "Why", or "Changed?" columns, not into prose.
- **IDs everywhere** (B01, S03, H2, BR1, SC1, Q1) so the strategist can reply in shorthand.
- **Times:** seconds in breakdowns and conversion (`0.000–2.703`). `m:ss` in the editor brief (`0:00–0:03`), because editors read timelines that way.
- **Emojis only as markers:** the section headers above, plus ✅ ✏️ ⚠️ 📊 🎯 inside tables. No decorative emojis.
- **Long breakdowns:** if the beat table and shot details make the message very long, send the breakdown first, then the options in the next part of the same reply. Never cut the breakdown short.

## Layout: message 1 (breakdown → options)

```
[one-line intro]

## 🎬 Inspiration breakdown
🎬 [Name] · [dur]s · [ratio] · [N] shots · [N] beats
[beat table]
[hook card]
[shot details, if the borrow needs them]
[format summary]

---
## 📊 Our data
[data card as a 2-column table, 6–10 rows]

---
## 🔁 Conversion        ← full copy / format only
[conversion table]

---
## ✍️ Options
[hook table] [bridge table, if this borrow has one] [body / concept tables]
[⚠️ Calls needed table (Q1…), if any]

---
## 👉 Your pick
[one short line saying exactly what to reply with, plus an example]
[if visuals were Unknown: one line asking for the video or screenshots of exactly those beats]
```

## Layout: message 2 (after picks)

```
[one-line confirmation of the picks, e.g. "Locked: V1 = H2, V2 = H3, BR4, SC1."]
[any one-line notes, max 2]

[the editor brief, exactly per editor-brief-template.md]
```
