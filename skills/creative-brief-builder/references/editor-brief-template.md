# Editor Brief Template

The editor works only from this brief. Write it so someone who didn't see the chat, and may not be a native English speaker, can make the video without asking a question.

Writing rules:
- Simple words, short lines, present tense ("Close-up of hand opening the box").
- Use the approved lines **exactly** as picked (including the strategist's edits). Don't rewrite them.
- No evidence tags, data talk, or strategy jargon. The editor needs *what* and *how*, plus at most one line of *why* where it changes how they edit.
- Every row's times must add up to the target length.
- If something is unknown (e.g. no proof asset yet), put it under **Open items**. Don't hide a guess inside the script.

Use this exact structure:

## Notes on filling it

- **Times:** start from the inspiration's timings for the borrowed parts, then adjust to the approved line lengths (spoken ≈ 2.5 words/s, on-screen ≈ 3 words/s).
- **"What we see":** one camera setup per row. If the borrowed visual is complex, it's fine to use 2–3 short sentences in the cell.
- **Body from our winner:** if the body is reused from the winner and the editor has that project file, write `Rows 4–9: reuse [winner ad] from 0:06 to end, no changes` instead of re-describing it, but only if the strategist confirmed the editor has it.
- **Several variations with different bodies** (rare): repeat the "Script & shots" table per variation, each with its own heading.
