P&L Enhancement — Design Direction

Keep everything that works. Add what's missing. Elevate the aesthetic.

What stays (untouched)

  • Live Profit Ticker (animated hero)
  • Date Range Picker
  • PnL Summary Cards (6 metrics)
  • Waterfall Chart + Margin Indicator
  • Net Profit Trend (30-day area chart)
  • Daily P&L Breakdown (multi-view chart)
  • COGS Manager tab + Breakdown tab
  • All existing data fetching & caching logic

What gets added / enhanced

A: Surgical Enhancement

Add below existing layout:
• Hourly Heatmap section (below daily breakdown)
• Chargebacks section (after heatmap)
• Product Performance table with real figures (replace current ProductPnLSection with corrected data)
• Digital/Physical COGS toggle baked into every component

UI upgrade: Swap hardcoded colors for CSS custom properties. Neutral palette (grays, one accent). Subtle glass borders. No gradient backgrounds. Monospace numbers.

Pros

  • Minimal risk of breaking
  • Fast to implement
  • Keeps familiar layout

Cons

  • Page gets longer
  • UI won't feel "new"

B: Sectioned Dashboard (Recommended)

Organize into collapsible sections:
• Section 1 — Pulse: Live ticker + today's mini KPIs (revenue, spend, margin, orders)
• Section 2 — Period View: Date picker + Summary cards + Waterfall + Margin
• Section 3 — Trends: Net profit trend + Daily breakdown (existing)
• Section 4 — Hourly: Heatmap (new)
• Section 5 — Products: Product performance table with real COGS/digital logic
• Section 6 — Chargebacks: Lost/Recovered tracker
• Section 7 — Settings: COGS Manager + Breakdown tabs

UI style: 2062 — monochrome surfaces, 1px borders, large typography for numbers, micro-labels, no color unless it encodes data (green=profit, red=loss). Glass-morphism subtle blur on section headers.

Pros

  • Organized, scannable
  • Future-proof structure
  • Collapsible = less scroll
  • Clean visual hierarchy

Cons

  • More code to write
  • Slightly more complex state

C: Tab-Based Views

Split P&L into top-level tabs:
• Overview tab: Ticker + KPIs + Waterfall + Margin
• Trends tab: All charts (trend, daily, hourly)
• Products tab: Full product performance + COGS manager
• Chargebacks tab: Dispute tracking

UI style: Same 2062 aesthetic. Each tab is a focused view.

Pros

  • Less scrolling per view
  • Focused contexts

Cons

  • Hides data behind tabs
  • User can't see everything at once
  • More navigation friction

Key Rules (All Approaches)

  • Digital products: COGS = $0, no COGS card/row/bar shown. Shipping = $0. Only show: Revenue, Ad Spend, Fees, Refunds, Net Profit
  • Physical products: Full COGS + Shipping displayed everywhere
  • Product table figures: Fetched from real Shopify order line items, aggregated by product ID. COGS from stored costs or 30% default (physical only)
  • Chargebacks: Lost + Recovered from Shopify dispute data
  • Color philosophy: Monochrome base. Green = money in. Red = money out. Nothing else.
